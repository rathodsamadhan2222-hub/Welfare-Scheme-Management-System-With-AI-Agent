# Welfare Schemes Management System with AI Agent

## Overview
A centralized platform that helps citizens discover government welfare schemes using AI-powered recommendations and natural language search.

## Features
- AI-powered scheme discovery
- Eligibility-based recommendations
- Role-based access (Admin & Citizen)
- JWT Authentication
- Real-time scheme search
- Application tracking
- Responsive UI

## Tech Stack

### Frontend
- Next.js
- React.js
- Tailwind CSS
- Zustand
- ShadCN UI

### Backend
- Node.js
- Express.js
- TypeScript

### AI
- OpenRouter
- GPT-4o-mini
- Function Calling

### Security
- JWT
- Bcrypt
- Rate Limiting
- Zod Validation

## Future Scope
- Government API Integration
- Mobile App

- Smart Notifications
